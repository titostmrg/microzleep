<p align="center"> MICROSLEEP DETECTION </p>
This application was built using Kotlin for its mobile application and a combination of MediaPipe and convolutional neural networks for its microsleep detection system, which can run automatically to provide early warnings to improve driver safety.

The application is designed to detect microsleep using MediaPipe Face Mesh by calculating eye opening values, which are then sent to CNN as additional input besides image input. This algorithm produces an accuracy of around 96%. The application provides an audible warning from the smartphone when microsleep is detected.
